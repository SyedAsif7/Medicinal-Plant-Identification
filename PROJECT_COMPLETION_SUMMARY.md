## 🎯 Usage Instructions

### Quick Start
1. **Run Setup**: `python setup.py` (one-time setup)
2. **Start Application**: Double-click `start_app.bat` or run `streamlit run app.py`
3. **Access Web UI**: Open browser to `http://localhost:8501`
4. **Use Application**: Upload plant image and click "Identify Plant"

### Alternative Methods
- **Command Line Testing**: `python test_project.py images/Amla/1300.jpg`
- **Manual Start**: `streamlit run app.py`
- **Setup Script**: `python setup.py` (validates installation)

## 📊 Technical Specifications

### Model Details
- **Architecture**: MobileNetV2 + Custom Layers
- **Input**: 224×224 RGB images
- **Output**: 40-class classification
- **Training**: 10 epochs with data augmentation
- **Framework**: TensorFlow 2.x / Keras

### System Requirements
- **Python**: 3.8+
- **RAM**: 4GB minimum
- **Storage**: 500MB free space
- **OS**: Windows, macOS, or Linux
